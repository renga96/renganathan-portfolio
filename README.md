# Renganathan Ramasamy — Portfolio

A responsive, single-page portfolio website built from the supplied 2026 resume.

## Preview locally
Open `index.html` in a browser. The resume download is in `assets/`.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, for example `renganathan-portfolio`.
3. Upload the contents of this folder (make sure `index.html` is at the repository root).
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. After GitHub Pages finishes publishing, copy the public URL shown there. It will usually look like `https://YOUR-USERNAME.github.io/renganathan-portfolio/`.
7. Add that URL to LinkedIn under **Contact info → Website**, and optionally share it as a post.

## Before publishing
This portfolio currently displays the phone number and email address from the supplied resume, and includes the resume PDF for download. Since GitHub Pages is public, remove either if you do not want those details publicly visible. The content is based on the supplied resume; review client/project disclosure against your employer confidentiality obligations before publishing.
